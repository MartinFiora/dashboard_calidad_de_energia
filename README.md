# 📈 Análisis de calidad de la energía ⚡

## Hito intermedio - Análisis Exploratorio

Para ejecutar el análisis, es necesario ubicarse en el directorio raíz del repositorio.

1. Instalar las dependencias:

```bash
pip install -r requirements.txt
```

2. Ejecutar el script de análisis:

```bash
python scripts/01_exploratorio.py
```

Los datos de entrada se encuentran en la carpeta `data/`. Los gráficos generados se exportan en formato HTML a la carpeta `output/` (se crea automáticamente si no existe).
